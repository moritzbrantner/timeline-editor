# Issue Tracker

GitHub Issues are the source of truth for planned work in this repository.

- Repository: `moritzbrantner/timeline-editor`
- Durable work queue: GitHub Issues
- Agent-loop queue source: GitHub Issues in `moritzbrantner/timeline-editor`

Substantial planned work should become a GitHub PRD issue unless the user explicitly asks for direct implementation. Tiny one-shot fixes may be implemented directly when they do not need a durable planning record.
